features:
  - "Opto mode: a leveling amplifier with Gain, Peak Reduction, and Compress / Limit"
  - "FET mode: a limiting amplifier with Input, Output, Attack, Release, and the 4, 8, 12, 20, and All ratio buttons"
  - "VCA mode: a compressor/limiter with Threshold, Compression, and Output Gain"
  - "Opto, FET, and VCA each measured against a reference unit"
  - "Bus, Studio FET, Studio VCA, Digital, and 4-band Multiband modes"
  - Needle meters with gain reduction and output scales
  - Sidechain filter on the Opto, VCA, and Bus faces
  - Mix control on every mode for parallel compression
  - Auto Makeup gain
  - User presets alongside the factory presets
  - "Mono and stereo operation"
  - Resizable interface
  - Full automation support

---

Multi-Comp 2 is the successor to Multi-Comp. It has its own plugin identity, so both can be installed side by side; keep the original for projects that already use it.

Multi-Comp 2 is open source under GPL-3.0-or-later. View the source, report issues, or contribute on [GitHub](https://github.com/dusk-audio/dusk-audio-plugins).
